# R4 — Checklist รายชื่อ Client ที่ออนไลน์

> R4 (0.5): Each client can see a list of names of all clients that are currently connected to the server including its own name.

## สิ่งที่ต้องเป็นจริง

| ข้อ | พฤติกรรม |
|---|---|
| รวมตัวเอง | ชื่อตัวเองอยู่บนสุดของรายชื่อ ต่อท้ายด้วย `(คุณ)` |
| ครบทุกคน | ทุก client เห็นรายชื่อชุดเดียวกัน และตัวเลข `ออนไลน์ (n)` ตรงกัน |
| คนเข้าใหม่ | ทุกคนเห็นชื่อเพิ่มทันทีโดยไม่ต้อง refresh และคนที่เพิ่งเข้าเห็นรายชื่อครบตั้งแต่แรก |
| คนออก | ปิด tab แล้วชื่อหายจากทุกเครื่องทันที |
| ไม่นับคนที่ยังไม่ login | คนที่เปิดหน้า login อยู่หรือ register ไม่ผ่าน ไม่อยู่ในรายชื่อ |
| server หลุด | client กลับไปหน้า login พร้อมข้อความ "หลุดการเชื่อมต่อจาก server" ไม่ค้างอยู่กับรายชื่อเก่า |

## ทดสอบด้วยมือ

- [ ] login `C1` → เห็น `ออนไลน์ (1)` และ `C1 (คุณ)`
- [ ] login `C2` อีก tab/เครื่อง → **C1 เห็น C2 เพิ่มทันที** (ไม่ refresh) ส่วน C2 เห็น `C2 (คุณ)` อยู่บนสุดตามด้วย `C1`
- [ ] login `C3` → ทั้ง 3 คนเห็น `ออนไลน์ (3)`
- [ ] เปิด tab ที่ 4 ค้างไว้ที่หน้า login (ยังไม่กดเข้า) → ทุกคนยังเห็น `ออนไลน์ (3)`
- [ ] ปิด tab ของ C3 → C1 และ C2 เห็น `ออนไลน์ (2)` ทันที
- [ ] กด `Ctrl+C` หยุด server → C1 และ C2 กลับไปหน้า login พร้อมข้อความหลุดการเชื่อมต่อ
