# R3 — Checklist ชื่อ Client ไม่ซ้ำกัน

> R3 (0.5): Each client must have a unique name.

## กฎของชื่อ

| กฎ | ตัวอย่าง |
|---|---|
| ห้ามซ้ำกับคนที่ออนไลน์อยู่ | มี `C1` อยู่แล้ว → `C1` เข้าไม่ได้ |
| ไม่สนตัวพิมพ์เล็ก/ใหญ่ | มี `C1` อยู่แล้ว → `c1` เข้าไม่ได้ |
| ตัดช่องว่างหัวท้าย | มี `C1` อยู่แล้ว → `"  C1 "` เข้าไม่ได้ |
| ยาว 1–20 ตัวอักษร | ว่าง / เว้นวรรคล้วน / 21 ตัว → เข้าไม่ได้ |
| ชื่อว่างอีกครั้งเมื่อเจ้าของออก | `C1` ปิด browser → คนอื่นใช้ `C1` ได้ |

## ทดสอบด้วยมือ

เปิด server และ client (เปิดหลาย tab ได้)

- [x] Tab 1: login เป็น `C1` → เข้าได้
- [x] Tab 2: login เป็น `C1` → ขึ้น `Name "C1" is already taken` และยังอยู่หน้า login
- [x] Tab 2: login เป็น `c1` → ขึ้นข้อความเดิม (ไม่สนตัวพิมพ์)
- [x] Tab 2: login เป็น `C2` → เข้าได้ **โดยไม่ต้อง refresh** เพราะ client ตัด connection เก่าทิ้งแล้วต่อใหม่
- [ ] ปิด Tab 1 → Tab 3: login เป็น `C1` → เข้าได้ (ชื่อว่างแล้ว) _(ยืนยันด้วย test อัตโนมัติแล้ว ยังไม่มี screenshot)_
- [x] terminal ของ server เห็น `[recv] ... -> register {"name":"C1"}` ของครั้งที่ถูกปฏิเสธด้วย
