# R5 + R6 — Checklist ห้องแชท

> R5 (0.5): Each chat between clients (both Private and Group message) must have its own chat room.
> R6 (0.5): Each chat room (both Private and Group message) must include a chat box for sending text messages and a chat window for displaying the sent messages and new incoming messages.

## การทำงาน

| สิ่งที่ต้องมี | วิธีที่ทำ |
|---|---|
| ห้องแยกกัน (R5) | ทุกห้องมี id ไม่ซ้ำกัน: `dm:<ชื่อคู่สนทนา>` / `group:<ชื่อกลุ่ม>` ข้อความเก็บแยกตาม id (`client/src/rooms.js`) |
| เปิดห้อง | คลิกชื่อในรายชื่อออนไลน์ → ห้อง private, คลิกกลุ่มที่เป็นสมาชิก → ห้อง group |
| Chat window (R6) | ทุกข้อความเป็นบรรทัดแบบ log `[เวลา] ผู้ส่ง: ข้อความ` ชื่อของตัวเองเป็นสีเขียว ของคนอื่นเป็นสีน้ำเงิน และ scroll ลงล่างสุดเองเมื่อมีข้อความใหม่ |
| Chat box (R6) | ช่องพิมพ์ + ปุ่มส่ง กด Enter ส่งได้ และส่งข้อความว่างไม่ได้ |
| ข้อความใหม่ในห้องที่ไม่ได้เปิด | ขึ้นตัวเลข unread ข้างชื่อห้อง |

## เตรียม

restart server + refresh client แล้ว login `C1`, `C2`, `C3` (3 tab หรือ 3 เครื่อง)

ตอนนี้ยังไม่มีปุ่มสร้างกลุ่มและเข้ากลุ่ม (R8, R10) ให้สร้างกลุ่มผ่าน DevTools Console ไปก่อน:

```js
// Console ของ C1
socket.emit("create_group", { group: "g1" })
// Console ของ C2
socket.emit("join_group", { group: "g1" })
```

## ห้อง Private

- [ ] C1 คลิก `C2` → เปิดห้อง `C2` (หัวห้องขึ้น "private · online") มีหน้าต่างข้อความ + ช่องพิมพ์
- [ ] C1 พิมพ์ `hi C2` แล้วกด Enter → ขึ้นบรรทัด `[hh:mm] C1: hi C2` (ชื่อสีเขียว) ในห้องของ C1
- [ ] C2 เห็น `[1]` ข้างชื่อ `@C1` → คลิกแล้วเห็นบรรทัด `[hh:mm] C1: hi C2` (ชื่อสีน้ำเงิน) และ `[1]` หายไป
- [ ] C2 ตอบ `hi C1` → C1 เห็นในห้องเดิม ข้อความเรียงลำดับถูกต้อง
- [ ] C3 ส่งหา C1 → C1 เห็นตัวเลขข้างชื่อ `C3` แยกห้องจาก `C2` ข้อความไม่ปนกัน

## ห้อง Group

- [ ] C1 และ C2 คลิก `g1` → เปิดห้อง `#g1` หัวห้องแสดงสมาชิก
- [ ] C3 เห็น `g1` แต่คลิกไม่ได้ (ยังไม่ได้เป็นสมาชิก)
- [ ] C2 พิมพ์ในห้อง g1 → C1 เห็นในห้อง g1 **ไม่ใช่**ในห้อง private ของ C2

## พฤติกรรมอื่น

- [ ] ส่งข้อความยาว ๆ หรือหลายบรรทัด → ข้อความตัดบรรทัดเอง ไม่ล้นหน้าจอ
- [ ] ส่งข้อความจนเกินความสูงหน้าต่าง → scroll ลงล่างสุดเอง
- [ ] C2 ปิด tab → ห้องของ C2 ในเครื่อง C1 ขึ้น "offline" และช่องพิมพ์ถูกปิด (ข้อความเก่ายังอยู่)

## มือถือ (Responsive)

เปิดบนมือถือ (หรือ DevTools → Toggle device toolbar → เลือก iPhone / Pixel)

- [ ] หลัง login เห็น**หน้ารายชื่อเต็มจอ** (ยังไม่มีห้องแชท)
- [ ] แตะ `@C2` หรือ `#g1` → **ห้องแชทเต็มจอ** มีปุ่ม `[< back]` มุมซ้ายบน และคีย์บอร์ดไม่เด้งขึ้นเอง
- [ ] แตะช่องพิมพ์ → คีย์บอร์ดขึ้นแล้วช่องพิมพ์ไม่ถูกบัง และหน้าไม่ zoom เข้า (iPhone)
- [ ] ระหว่างอยู่ในห้อง C2 มีข้อความเข้าห้องอื่น → ปุ่มเปลี่ยนเป็น `[< back (1)]`
- [ ] แตะ `[< back]` → กลับหน้ารายชื่อ เห็น `[1]` ข้างห้องที่มีข้อความใหม่
- [ ] ข้อความยาว ๆ ตัดบรรทัดเต็มความกว้างจอ ไม่ล้นจอ ไม่มี scroll แนวนอน
- [ ] บนคอม (จอกว้าง) ยังเห็นรายชื่อ + ห้องแชทพร้อมกัน และไม่มีปุ่ม `[< back]`

## ทดสอบอัตโนมัติ

รันเอง: `cd server && npm test -- r05`

ส่งข้อความจริงผ่าน server แล้วแยกห้องด้วยฟังก์ชันจาก `rooms.js` ผ่าน 9/9:
ข้อความไปและกลับอยู่ห้องเดียวกัน, ทั้งสองฝั่งเห็นบทสนทนาเดียวกัน, คู่สนทนาคนละคนอยู่คนละห้อง,
ห้อง group แยกจากห้อง private, client ได้เฉพาะห้องที่ตัวเองเกี่ยวข้อง, id ห้อง private และ group ไม่ชนกัน
