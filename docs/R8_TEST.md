# R8 — Checklist สร้างกลุ่ม

> R8 (1.0): Each client can create a chat group(s), which initially includes only themselves as a member.

## การทำงาน

```
C1 พิมพ์ชื่อกลุ่ม + กด "สร้าง"
  └─ emit("create_group", {group:"g1"}) ──> server
                                             1. register แล้วหรือยัง?               → NOT_REGISTERED
                                             2. ชื่อว่างหรือยาวเกิน 30?               → INVALID_GROUP
                                             3. ชื่อซ้ำ (ไม่สนตัวพิมพ์)?               → GROUP_EXISTS
                                             4. groups.set("g1", {C1})  ← สมาชิกมีแค่ผู้สร้าง
                                             5. socket ของ C1 join room "group:g1"
ทุกคน <── group_list (ทุกคนเห็น g1 สมาชิก: C1) ┤
C1    <── create_group_ok ──────────────────┘  → client เปิดห้อง # g1 ให้ทันที
```

- สร้างได้หลายกลุ่ม ไม่จำกัดจำนวน
- **ไม่มีการเพิ่มคนอื่นเข้ากลุ่มอัตโนมัติ** คนอื่นต้องกด join เอง (R10)
- กลุ่มที่สมาชิกออกหมดแล้ว**ยังอยู่** ขึ้นว่า "ไม่มีสมาชิก" ให้คนอื่น join ได้ และชื่อนั้นยังถือว่าถูกใช้อยู่

## ทดสอบด้วยมือ

restart server + refresh client แล้ว login `C1`, `C2`

- [ ] C1 พิมพ์ `g1` แล้วกด "สร้าง" → ห้อง `# g1` เปิดให้ทันที หัวห้องขึ้น "สมาชิก 1 คน: C1"
- [ ] C2 เห็น `g1` ใน sidebar ทันที มีสมาชิกแค่ `C1` และขึ้น "ยังไม่ได้เป็นสมาชิก" (คลิกไม่ได้)
- [ ] C1 สร้าง `g2` เพิ่ม → C1 เป็นสมาชิกทั้ง g1 และ g2
- [ ] C2 สร้าง `G1` → ขึ้น `มีกลุ่มชื่อ "G1" แล้ว` (ไม่สนตัวพิมพ์)
- [ ] C2 สร้าง `c2-group` → C2 เป็นสมาชิกคนเดียว และ C1 ไม่ได้ถูกเพิ่มเข้าไป
- [ ] C1 ปิด tab → C2 เห็น g1 และ g2 ขึ้น "ไม่มีสมาชิก" แต่กลุ่มยังอยู่

## ทดสอบอัตโนมัติ (ที่ AI รันแล้ว)

ผ่าน 15/15: ผู้สร้างได้ `create_group_ok`, สมาชิกเริ่มต้นมีแค่ผู้สร้าง, client อื่นเห็นกลุ่มแต่ไม่ถูกเพิ่มเข้าไปเอง,
client อื่นไม่ได้รับ `create_group_ok`, สร้างได้หลายกลุ่ม, ชื่อซ้ำตรงตัว / ต่างแค่ตัวพิมพ์ / มีช่องว่างหัวท้าย → `GROUP_EXISTS`,
ชื่อว่าง / เว้นวรรคล้วน / 31 ตัว → `INVALID_GROUP`, ชื่อภาษาไทย 30 ตัวผ่าน, ยังไม่ register → `NOT_REGISTERED`,
ผู้สร้างอยู่ใน room ของกลุ่มและได้รับ `group_msg`, คนที่ไม่ใช่สมาชิกไม่ได้รับ `group_msg`, ผู้สร้างออกแล้วกลุ่มยังอยู่แบบไม่มีสมาชิก,
ชื่อของกลุ่มที่ไม่มีสมาชิกยังถือว่าถูกใช้อยู่
