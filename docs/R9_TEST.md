# R9 — Checklist รายชื่อกลุ่มทั้งหมด + สมาชิก

> R9 (1.0): Each client can see a list of all existing chat groups (with the member list) created by any client.

## การทำงาน

server ส่ง `group_list` (กลุ่ม**ทั้งหมด**พร้อมสมาชิก) ให้ทุกคนที่ register แล้ว ทุกครั้งที่ข้อมูลกลุ่มเปลี่ยน:

| เหตุการณ์ | ทำไมต้องส่ง |
|---|---|
| มีคน register | คนที่เพิ่งเข้าต้องเห็นกลุ่มที่มีอยู่ก่อนครบ |
| `create_group` | ทุกคนต้องเห็นกลุ่มใหม่ |
| `join_group` | รายชื่อสมาชิกเปลี่ยน |
| disconnect | คนที่ออกถูกเอาออกจากทุกกลุ่ม |

- แสดง**ทุกกลุ่ม** ไม่ว่าใครเป็นคนสร้าง และไม่ว่าเราจะเป็นสมาชิกหรือไม่
- แต่ละกลุ่มแสดง `<จำนวน> คน: <รายชื่อ>` ชื่อตัวเองมี `(คุณ)` ต่อท้าย
- กลุ่มที่ยังไม่ได้เป็นสมาชิกขึ้น "ยังไม่ได้เป็นสมาชิก" ส่วนกลุ่มที่ไม่มีใครอยู่ขึ้น "ไม่มีสมาชิก"
- เรียงตามลำดับที่สร้าง

## ทดสอบด้วยมือ

restart server + refresh client แล้ว login `C1`, `C2`

- [ ] C1 สร้าง `g1`, C2 สร้าง `g2` → **ทั้งสองคน**เห็น `g1` และ `g2` พร้อมสมาชิก
- [ ] C1 เห็น g2 ขึ้น `1 คน: C2 · ยังไม่ได้เป็นสมาชิก` และเห็น g1 ขึ้น `1 คน: C1 (คุณ)`
- [ ] login `C3` ทีหลัง → เห็น g1, g2 ครบทันที
- [ ] (Console C3) `socket.emit("join_group", { group: "g1" })` → **ทุกคน**เห็น g1 เปลี่ยนเป็น `2 คน: C1, C3`
- [ ] C1 ปิด tab → C2, C3 เห็น g1 เปลี่ยนเป็น `1 คน: C3`

## ทดสอบอัตโนมัติ (ที่ AI รันแล้ว)

ผ่าน 10/10: ยังไม่มีกลุ่ม → ได้รายการว่าง, เห็นกลุ่มจากผู้สร้างทุกคน, คนที่ไม่ใช่สมาชิกเห็นกลุ่มพร้อมรายชื่อสมาชิก,
ทุก client ได้รายการชุดเดียวกัน, คนที่เพิ่งเข้าได้กลุ่มที่มีอยู่ครบทันที, join แล้วทุกคนเห็นสมาชิกอัปเดต,
disconnect แล้วสมาชิกถูกเอาออกทุกเครื่อง, เรียงตามลำดับที่สร้าง, กลุ่มที่ไม่มีสมาชิกยังอยู่ในรายการ,
socket ที่ยังไม่ register ไม่ได้รับ `group_list`
